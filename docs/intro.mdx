# Добро пожаловать в Analitex Docs

Это основной портал документации проекта Analitex.

## Что здесь хранится

- Гайды для команды, клиентов и партнёров
- Инструкции по работе с продажами на маркетплейсах
- Техническая, юридическая и организационная документация

## Быстрый старт

1. Откройте нужный раздел через левое меню.
2. Используйте поиск по сайту для быстрого доступа к страницам.
3. Если нашли неточность, нажмите `Edit this page` и предложите правку.

## Полезно знать

- Основная локаль сайта: `ru`
- Английская версия доступна через переключатель языков в верхнем меню
- Контент синхронизируется из `analitex-docs` при деплое
